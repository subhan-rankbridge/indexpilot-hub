# IndexPilot — Article Indexing, Own Engine

IndexPilot is an article indexing checker and submission service with its own engine: submitted links are listed publicly so search crawlers can reach them.

**Public hub of submitted links:**
https://indexpilot-tawny.vercel.app/hub

**Live site:** https://indexpilot-tawny.vercel.app

## How it works
- Users submit article URLs through the app.
- Each new link costs 1 credit and is listed on the public hub page and RSS feed.
- Search crawlers that visit the hub can follow the links and discover the articles.
- Listing is a discovery signal only — it does not guarantee indexing.
